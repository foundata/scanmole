# scanmole-gui

The GTK4/libadwaita desktop frontend for [ScanMole](https://pypi.org/project/scanmole/): easy document scanning for Linux, from ADF duplex batches to searchable PDFs. It wraps the `scanmole` CLI and contains no scanning logic itself.

Full documentation, screenshots and the FAQ live in the [ScanMole project README](https://github.com/foundata/scanmole#readme).
