# scanmole

The ScanMole CLI scanning engine: scan documents from a SANE scanner straight to
a searchable PDF. Made for servers, scripts and as the backend of
`scanmole-gui`. Its only Python dependency is Pillow, used for raster rotation;
scanning, PDF assembly and OCR use external tools.

Full documentation, screenshots and the FAQ live in the
[ScanMole project README](https://github.com/foundata/scanmole#readme).
